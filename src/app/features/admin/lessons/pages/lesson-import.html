Upload a grammar lesson JSON file

Choose a UTF-8 JSON array of 1–100 lessons, up to 5 MiB (5,242,880 bytes). Each item requires level, lessonNumber, title, displayOrder, schemaVersion: 1, expectedVersion, and content. Description is optional.

For new or absent content use expectedVersion: 0 and omit etag. Replacing existing content requires its positive version and exact quoted ETag in the file's etag field. Files are uploaded exactly as selected.

Local checks cover metadata and grammar schema v1. The server checks duplicate JSON keys, existing levels, occupied display orders, revisions, and its configured limits before writing. Swapping occupied display orders is unsupported.
